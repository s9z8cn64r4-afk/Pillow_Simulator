# Roadmap

| Milestone | Inhalt | Exit-Gate (Kurz) | Schätzung* |
|---|---|---|---|
| **M0 Planning** | Recherche, GDD, Economy-Sim, TDD, ADRs, MVP-Scope, Backlog | Dokumente widerspruchsfrei, Sim erfüllt Zielkurven, Scope (vorläufig) frei | Sitzung 1 |
| **M1 Prototype** | Graybox-Zone, Schlagen + Auto-Swing, Federn, Shop (3 Kissen, 2 Upgrades), ProfileStore, HUD, Net-Layer, Tests | 10 Min. spielen, kaufen, rejoinen, Stand bleibt `[VERIFIZIERT]`; Exploit-Basistests bestanden | 2–3 Sitzungen |
| **M2 Alpha** | Alle Kissen/Zonen, Puppen, Rebirth, Ranks, Map final-nah, Animationen/VFX, UI-Design-System, Tutorial, Settings | Pfad Start → Rebirth 3 per Bot + manuell; keine P0/P1; Performance-Budgets | 5–7 Sitzungen |
| **M3 Closed Beta** | Daily, Codes, Leaderboards, Gruppen-/Freunde-Bonus, Monetarisierung (Test), Analytics, Relay + Discord, Feedback, Mobile-Feinschliff, 10–30 Tester | ≥ 20 Sessions ausgewertet, Tutorial ≥ 80 %, Owner-Scope-Freigabe | 4–6 Sitzungen + Testzeit |
| **M4 Open Beta** | Stresstest, Store-Seite, Icon/Thumbnails, Community-Discord öffentlich | Alle MVP-Kriterien verifiziert, Rollback getestet | 2–3 Sitzungen + 1–2 Wochen |
| **M5 Release 1.0** | Production nach Owner-Freigabe, 72 h verstärktes Monitoring | 7 Tage stabil | – |
| **M6.x LiveOps** | 1.1 Pets & Eggs + Quests · 1.2 Welt 2 · 1.3 Event · 1.4 Achievements | je Update Post-Review | 2-Wochen-Takt |

*KI-Sitzungen, abhängig von Owner-Freigaben und Testerzahl.
