# Art Bible v1

- **Formen:** rund, gepolstert, übertriebene Proportionen; keine scharfen Kanten außer Hotel-Gold-Details.
- **Farben je Zone:** Bedroom (Pastellblau, Holz, Sternchen) · Lounge (Pfirsich, Lichterketten-Gelb) · Hotel (Bordeaux, Gold, Creme) · Cloud Kingdom (Weiß, Lavendel, Mondsilber).
- **Kissen:** Grundkörper gewölbt, sichtbare Naht, Varianten durch Muster/Material/Accessoires (Quasten, Krone, Blitze). Polycount ≤ 2.000 Tris. Seltenheit erkennbar an Aura (ab Epic) und Trail (Legendary).
- **Licht:** warm, weiche Schatten, `Future`-Beleuchtung nur wenn Mobile-FPS-Budget hält, sonst `ShadowMap`.
- **Lesbarkeit vor Detail:** Spieler und Federn müssen auf 6-Zoll-Phones immer sichtbar sein; Hintergrund gedämpfter als Vordergrund.
- **Produktionsweg:** 1. Studio-Generierung (Mesh/Textur/Material) · 2. prozedural per Luau (Graybox, Möbel) · 3. Creator Store (nur frei nutzbar, Skripte entfernen, ins Asset-Log).
